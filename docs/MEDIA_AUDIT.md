  - *Freedom to share and adapt the material with appropriate credit.*
- **Required Extraction Path:**
  ```bash
  data/raw/RDD2022_India/
  ├── train/
  │   ├── images/
  │   └── annotations/xmls/
  ```
- **Policy Compliance:** Because the archive exceeds 13 GB and network access must remain strictly deterministic and offline, downloading large dataset archives is not permitted in automated CI runs. The application continues functioning cleanly using verified demo media and clear provenance labels.
